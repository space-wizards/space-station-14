# Class feats through level 5

Imported through level 5 from remaster Pathfinder books under the ORC license (Player Core, Player Core 2, and later ORC books).
Each class has its own folder. A feat that more than one class can take is copied into each of those folders.
The level 1 and level 2 class feat buttons list the chosen class. Level 4 feats are in the folders and are not on a button yet.
A chosen feat trains its skills on the character sheet, including a named Lore. A land Speed bonus is applied at spawn.
Anything else says: This feature will be implemented later.
