# Ancestry feats through level 5

Imported through level 5 from remaster Pathfinder books under the ORC license (Player Core, Player Core 2, and later ORC books).
Each feat is its own file in that ancestry folder.
Android, Azarketi, and Fleshwarp are not here. Their feats are still the pre-remaster Ancestry Guide.
A chosen feat trains its skills on the character sheet, including a named Lore.
A land Speed bonus is applied at spawn.
An activity, extra attack, or granted feat the game cannot perform yet says: TBA - action will be added.
