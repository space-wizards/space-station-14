# CarpFinder: classes

One `cfClass` file per class.

- `Core/` is Pathfinder Player Core.
- `Expanded/` is Player Core 2 and the later remaster books under the ORC license.

The numbers on each class are the level 1 chassis: hit points, key ability, perception, saves, fixed skills, attacks, defenses, and level 1 spell slots. Features through level 5 are listed on the class. A feature the game does not run yet says it will be implemented later.

Bard, Fighter, Alchemist, and Barbarian use that remaster chassis. Kineticist is not included.
