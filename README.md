# Space Arena

Space Station 14 — это ремейк SS13, работающий на собственном движке [Robust Toolbox](https://github.com/space-wizards/RobustToolbox), написанном на C#.

Это репозиторий исходного кода билда русскоязычного сервера **SpaceArena**, основанного на [оригинальном проекте Space Wizards Federation](https://github.com/space-wizards/space-station-14).
